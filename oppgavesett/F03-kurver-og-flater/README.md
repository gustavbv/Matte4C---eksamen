# F3 Kurver og flater

**I pensum:** Parametriserte kurver (fart, akselerasjon, tangentlinje, buelengde, glatthet), parametriserte flater, tangentplan, normalvektor.

**Ikke pensum (finnes i gamle eksamener):** Krumning, enhetsnormal N, torsjon, alle integraler.

113 oppgaver: 78 helt i pensum, 26 delvis og 9 grensetilfeller.

Hver oppgave er to PDF-er ved siden av hverandre: `…-oppgave.pdf` og løsningsforslaget `…-svar.pdf`. Filnavnet sier nummer, emne, år, semester og oppgavenummer, for eksempel `005-TMA4135-2016-host-oppg5-oppgave.pdf`. Undermappene kommer i anbefalt rekkefølge:

- [`1-TMA4432-ovinger-og-proveeksamen/`](1-TMA4432-ovinger-og-proveeksamen/): Fra TMA4432 (øvinger og prøveeksamen) (4)
- [`3-hele-oppgaven-i-pensum/`](3-hele-oppgaven-i-pensum/): Andre eksamener: hele oppgaven er pensum (74)

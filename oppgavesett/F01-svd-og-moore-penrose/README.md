# F1 SVD og Moore–Penrose

**I pensum:** SVD (full og redusert), beste rang-k-approksimasjon, Moore–Penrose, minste kvadrater og minste norm.

**Ikke pensum (finnes i gamle eksamener):** Polar dekomposisjon, normale operatorer, LU.

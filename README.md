# Matte 4C (TMA4432) – oppgavebank til eksamen

Oppgaver fra gamle eksamener på wiki.math.ntnu.no, sortert etter forelesningene i TMA4432 Matematikk 4C, høst 2026 (eksamen 24.11.2026). Hver oppgave er vurdert mot pensum, og hver rad lenker til oppgaven og løsningsforslaget.

Totalt 882 oppgaver: 637 **Ja** (hele oppgaven er pensum), 147 **Delvis** (bare noen deloppgaver) og 98 **Grense** (bare repetert eller like utenfor).

## Rekkefølge i hvert sett

I hvert oppgavesett kommer TMA4432 sine egne øvinger og prøveeksamen først, så Bergmanns eksamener, så andre eksamener der hele oppgaven er pensum, så oppgaver der bare deler er pensum, og til slutt grensetilfeller. Bergmann har laget eksamenene i TMA4125 vår 2022–2025 (med kontinuasjon) og TMA4215 høst 2021–2023.
